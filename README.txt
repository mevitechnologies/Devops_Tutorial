3. Open index.html in a modern browser.
4. Internet access is recommended for Bootstrap assets, the official Mevi Technologies logo, and external documentation links. The included learning diagrams and reference snapshots are local.

Safety
- Run commands only in environments you are authorised to manage.
- Review cloud cost and permissions before provisioning resources.
- Confirm your Kubernetes context before changing cluster resources.
- Never commit passwords, tokens, private keys or cloud credentials.
- Treat destructive commands and production deployments with care.
